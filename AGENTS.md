## Site architecture

- Keep reusable AI automation and delivery-process sections in shared site components so the homepage and services page remain consistent.
- Keep service descriptions and deliverables in the shared site data module so offerings remain consistent across pages.
- Treat unverified testimonials as explicitly labelled illustrative placeholders; never render invented names, ratings, or credentials as client proof.
